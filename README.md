# نظام إدارة حسابات العملاء

تطبيق ويب لإدارة حسابات العملاء (فواتير + دفعات) بواجهة عربية بالكامل واتجاه من اليمين لليسار.
هذه **النسخة الأمامية (Front-end)** فقط — تُخزَّن البيانات مؤقتاً في متصفح المستخدم
(`localStorage`) تمهيداً لربطها بخادم لاحقاً.

## التشغيل

افتح ملف `index.html` مباشرةً في المتصفح. لا يحتاج التطبيق إلى أي خادم أو تثبيت.

## حسابات الدخول التجريبية

| النوع | اسم المستخدم | كلمة المرور |
|------|---------------|--------------|
| موظف | `موظف` | `1234` |
| مدير | `مدير` | `1234` |

## الصلاحيات

### الموظف
- البحث عن عميل بالاسم.
- عند إيجاد العميل تظهر أمامه خيّاران:
  - **إضافة فاتورة**: جدول من أربعة أعمدة (وصف الصنف، العدد، السعر، الإجمالي) مع
    إمكانية إضافة صفوف وحساب المجموع تلقائياً.
  - **إضافة دفعة**: إدخال المبلغ المدفوع مع ملاحظة.
- يُسجَّل تاريخ ووقت كل فاتورة ودفعة **تلقائياً**.

### المدير
يرى جميع العملاء إضافةً إلى تبويبات:
- **العملاء**: قائمة بجميع العملاء مع الرصيد المستحق (إجمالي الفواتير − إجمالي الدفعات).
- **المبيعات اليومية**: إجمالي المبيعات مجمّعاً حسب اليوم.
- **المبيعات الشهرية**: إجمالي المبيعات مجمّعاً حسب الشهر.
- **كشف الحسابات**: كشف مختصر لكل عميل.
- **ملف العميل**: بالضغط على أي عميل تظهر كل فواتيره ودفعاته وأرصدته.

## بنية الملفات

```
index.html      الهيكل العام للصفحة
css/styles.css  التنسيقات (RTL + تصميم عربي)
js/data.js      طبقة البيانات والأسماء التجريبية والتخزين المحلي
js/app.js       منطق التطبيق (الدخول، الموظف، المدير، التقارير)
```

## الخطوات القادمة (Back-end)

المرحلة الحالية أمامية فقط. الخطوات المقترحة لاحقاً كمهام منفصلة:

1. إنشاء واجهة برمجية (API) للعملاء والفواتير والدفعات.
2. قاعدة بيانات حقيقية بدل `localStorage`.
3. مصادقة وصلاحيات حقيقية للمستخدمين (موظف / مدير).
4. طباعة الفواتير وكشوف الحسابات وتصديرها.
